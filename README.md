# Telegram Relay Bot (TG 消息转发机器人)

这是一个功能强大的 Telegram 机器人，专注于群组消息的定制化转发与数据统计。它可以将群组内的消息按需转发给指定用户，并提供消息重组、去源、编号及可视化数据分析功能。

## ✨ 核心功能

### 1. 🤖 群组消息接管
- 机器人可加入任意 Telegram 群组
- 实时监听并捕获群组内的消息内容
- 支持文本、图片、视频、文档、语音等多种媒体类型
- **媒体组支持**：多张图片/视频一次发送时，作为一个整体转发

### 2. ⚙️ 灵活的转发配置
- 提供直观的 Web 后台管理界面
- **多 Bot 支持**：可同时运行多个 Telegram Bot，每个 Bot 独立管理自己的群组
- **群组-用户多对多关联**：每个群组可独立配置转发给哪些用户
- 支持启用/禁用 Bot、群组和用户
- 实时配置，立即生效

### 3. 📝 消息重组与清洗
转发出的消息经过特殊处理：
- **隐私保护**：移除原始消息的转发来源标识，保护原始群组信息
- **独立编号**：每个接收用户的消息序号独立递增，方便追踪
- **自定义用户标记**：
  - 管理员可为每个接收用户设置独特标记（如 "A"、"客服1"、"业务A" 等）
  - 转发消息时显示：`标记+序号`（如 `A1024`、`客服11024`）
  - 未设置标记时默认显示：`#序号`（如 `#1024`）

### 4. 📊 数据统计与可视化
提供详细的数据分析面板：
- **消息量趋势图**：直观展示消息发送量的时间变化
- **时段分布图**：统计消息发送的热门时间段
- **发送者统计**：查看各发送者的消息占比和详情

## 🚀 快速开始

### 环境要求
- Python 3.12+
- Telegram Bot Token

### 1. 安装依赖

```bash
# 克隆项目
git clone <your-repo-url>
cd tg-relay-bot

# 使用 uv 安装依赖（推荐）
uv sync

# 或使用 pip
pip install -r requirements.txt
```

### 2. 配置 Bot Token

在项目根目录创建 `.env` 文件：

**单个 Bot：**
```bash
BOT_TOKEN=你的机器人token
```

**多个 Bot（推荐）：**
```bash
BOT_TOKEN=第一个机器人token
BOT_TOKEN_1=第二个机器人token
BOT_TOKEN_2=第三个机器人token
# 可以继续添加 BOT_TOKEN_3, BOT_TOKEN_4, ...
```

每个 Bot 会自动导入到数据库，并可以在后台管理页面查看和管理。

### 3. 启动服务

**推荐方式**（快速退出）：
```bash
python main.py
```
- ✅ 按 Ctrl+C **一次**即可退出
- ✅ 退出速度快（3 秒内）

**热重载模式**（仅调试时使用）：
```bash
python main.py --reload
```
- ✅ 修改代码自动重启
- ❌ 退出需要按 2-3 次 Ctrl+C

### 4. 访问管理后台

打开浏览器访问：
```
http://localhost:8000
```

## 📖 使用指南

### 用户注册

1. 用户向机器人私聊发送 `/start` 命令
2. 机器人会返回用户 ID
3. 管理员在后台启用该用户

### 后台管理

访问 http://localhost:8000 进行配置：

#### Bot 管理 (`/bots`)
- 查看所有 Bot 实例
- 启动/停止 Bot
- 查看每个 Bot 管理的群组数量
- Bot Token 会从环境变量自动导入

#### 群组管理（首页 `/`）
- 查看所有已接入的群组
- 每个群组显示所属的 Bot
- 启用/禁用群组转发
- **点击"配置用户"**：为每个群组选择接收消息的用户

#### 用户管理 (`/users`)
- 查看所有注册用户
- **设置用户标记**：为每个用户设置独特的标记（如 "A"、"客服1"），用于消息转发时的标识
- 启用/禁用用户
- 查看用户的当前消息序号
- 用户可以接收来自多个 Bot 的群组消息

#### 数据统计 (`/stats`)
- 查看各用户标记的消息量统计
- 点击标记查看详细统计
- 查看消息时间分布图表

### 群组转发流程

1. **将机器人拉入群组**
   - 群组会自动注册到系统

2. **配置转发用户**
   - 在后台点击该群组的"配置用户"按钮
   - 勾选要接收消息的用户
   - 保存配置

3. **启用群组和用户**
   - 确保群组状态为"已启用"
   - 确保目标用户状态为"已启用"

4. **开始转发**
   - 群组内的消息将自动转发给配置的用户

## 💡 消息格式

转发的消息格式：

**设置了标记的用户示例**（如标记为 "A"）：
```
A1024
这是转发的消息内容...
```
- `A`: 接收用户的自定义标记
- `1024`: 该接收用户的消息序号（每个用户独立计数）

**标记为中文的示例**（如标记为 "客服1"）：
```
客服11024
这是转发的消息内容...
```
- `客服1`: 接收用户的自定义标记
- `1024`: 该接收用户的消息序号

**未设置标记的用户示例**：
```
#1024
这是转发的消息内容...
```
- `#1024`: 只显示接收者的消息序号

**媒体组示例**（多张图片）：
```
📷 图片1  ← A1025
📷 图片2     产品的三个角度
📷 图片3
```
- 多张图片作为一个整体转发
- 只在第一张图片显示标记、序号和描述

## ⚠️ 常见问题

### Q: 为什么退出需要按多次 Ctrl+C？
A: 如果你使用了 `--reload` 参数或 `run_reload.py`，热重载会创建额外进程导致退出慢。请使用 `python main.py`（默认不开热重载）。

### Q: 如何修改代码并测试？
A: 修改代码后，手动重启即可：
```bash
# 按 Ctrl+C 退出
# 然后重新启动
python main.py
```

### Q: 群组消息没有转发？
A: 检查：
1. 群组是否已启用（后台首页查看状态）
2. 是否为群组配置了目标用户（点击"配置用户"）
3. 目标用户是否已启用（用户管理页面查看）

### Q: 多张图片被拆分成多条消息？
A: 已修复。现在会检测媒体组并作为整体转发。如果仍有问题，请重启服务。

### Q: 如何添加多个 Bot？
A: 在 `.env` 文件中配置多个 token（BOT_TOKEN, BOT_TOKEN_1, BOT_TOKEN_2...），然后重启服务。Bot 会自动导入到数据库，可以在 Bot 管理页面查看和管理。

### Q: 多个 Bot 之间会互相影响吗？
A: 不会。每个 Bot 独立管理自己的群组，互不干扰。用户可以同时接收来自多个 Bot 的消息。

### Q: 如何停止某个 Bot？
A: 在 Bot 管理页面点击"停止"按钮。停止后，该 Bot 下的所有群组将暂停转发。

### Q: 如何为用户设置标记？
A: 在用户管理页面 (`/users`)，每个用户都有一个"标记"输入框。输入你想要的标记（如 "A"、"客服1"、"业务部" 等），点击"保存"即可。设置后，该用户收到的所有消息都会显示这个标记。

### Q: 用户标记可以使用中文吗？
A: 可以！标记支持任意字符，包括中文、英文、数字等，最长 10 个字符。

### Q: 如果不设置标记会怎样？
A: 如果用户没有设置标记，消息会默认显示 `#序号` 格式（如 `#1024`）。

## 🛠 技术栈

- **后端框架**: FastAPI + Uvicorn
- **Bot 框架**: aiogram 3.x
- **数据库**: SQLite + SQLAlchemy (异步)
- **前端**: Tailwind CSS + Jinja2 模板
- **图表**: Chart.js
- **Python**: 3.12+
