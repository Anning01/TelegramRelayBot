# Telegram Relay Bot (TG 消息转发机器人)

这是一个功能强大的 Telegram 机器人，专注于群组消息的定制化转发与数据统计。它可以将群组内的消息按需转发给指定用户，并提供消息重组、去源、编号及可视化数据分析功能。

## ✨ 核心功能

### 1. 🤖 群组消息接管
- 机器人可加入任意 Telegram 群组
- 实时监听并捕获群组内的消息内容
- 支持文本、图片、视频、文档、语音等多种媒体类型
- **媒体组支持**：多张图片/视频一次发送时，作为一个整体转发

### 2. ⚙️ 灵活的转发配置
- 提供直观的 Web 后台管理界面
- **群组-用户多对多关联**：每个群组可独立配置转发给哪些用户
- 支持启用/禁用群组和用户
- 实时配置，立即生效

### 3. 📝 消息重组与清洗
转发出的消息经过特殊处理：
- **隐私保护**：移除原始消息的转发来源标识，保护原始群组信息
- **独立编号**：每个接收用户的消息序号独立递增，方便追踪
- **智能发送者标记**：
  - 英文用户名：显示首字母（如 "John" → `J1024`）
  - 非英文用户名：只显示序号（如 "张三" → `#1024`）

### 4. 📊 数据统计与可视化
提供详细的数据分析面板：
- **消息量趋势图**：直观展示消息发送量的时间变化
- **时段分布图**：统计消息发送的热门时间段
- **发送者统计**：查看各发送者的消息占比和详情

## 🚀 快速开始

### 环境要求
- Python 3.12+
- Telegram Bot Token

### 1. 安装依赖

```bash
# 克隆项目
git clone <your-repo-url>
cd tg-relay-bot

# 使用 uv 安装依赖（推荐）
uv sync

# 或使用 pip
pip install -r requirements.txt
```

### 2. 配置 Bot Token

在项目根目录创建 `.env` 文件：

```bash
BOT_TOKEN=你的机器人token
```

### 3. 启动服务

**推荐方式**（快速退出）：
```bash
python main.py
```
- ✅ 按 Ctrl+C **一次**即可退出
- ✅ 退出速度快（3 秒内）

**热重载模式**（仅调试时使用）：
```bash
python main.py --reload
```
- ✅ 修改代码自动重启
- ❌ 退出需要按 2-3 次 Ctrl+C

### 4. 访问管理后台

打开浏览器访问：
```
http://localhost:8000
```

## 📖 使用指南

### 用户注册

1. 用户向机器人私聊发送 `/start` 命令
2. 机器人会返回用户 ID
3. 管理员在后台启用该用户

### 后台管理

访问 http://localhost:8000 进行配置：

#### 群组管理（首页）
- 查看所有已接入的群组
- 启用/禁用群组转发
- **点击"配置用户"**：为每个群组选择接收消息的用户

#### 用户管理 (`/users`)
- 查看所有注册用户
- 启用/禁用用户
- 查看用户的当前消息序号

#### 数据统计 (`/stats`)
- 查看各发送者标记的消息量
- 点击标记查看详细统计
- 查看消息时间分布图表

### 群组转发流程

1. **将机器人拉入群组**
   - 群组会自动注册到系统

2. **配置转发用户**
   - 在后台点击该群组的"配置用户"按钮
   - 勾选要接收消息的用户
   - 保存配置

3. **启用群组和用户**
   - 确保群组状态为"已启用"
   - 确保目标用户状态为"已启用"

4. **开始转发**
   - 群组内的消息将自动转发给配置的用户

## 💡 消息格式

转发的消息格式：

**英文用户名示例**（如 "John Smith"）：
```
J1024
这是转发的消息内容...
```
- `J`: 发送者标记首字母（取自 "John"）
- `1024`: 接收者的消息序号（每个用户独立计数）

**非英文用户名示例**（如 "张三"）：
```
#1024
这是转发的消息内容...
```
- `#1024`: 只显示接收者的消息序号

**媒体组示例**（多张图片）：
```
📷 图片1  ← J1025
📷 图片2     产品的三个角度
📷 图片3
```
- 多张图片作为一个整体转发
- 只在第一张图片显示序号和描述

## ⚠️ 常见问题

### Q: 为什么退出需要按多次 Ctrl+C？
A: 如果你使用了 `--reload` 参数或 `run_reload.py`，热重载会创建额外进程导致退出慢。请使用 `python main.py`（默认不开热重载）。

### Q: 如何修改代码并测试？
A: 修改代码后，手动重启即可：
```bash
# 按 Ctrl+C 退出
# 然后重新启动
python main.py
```

### Q: 群组消息没有转发？
A: 检查：
1. 群组是否已启用（后台首页查看状态）
2. 是否为群组配置了目标用户（点击"配置用户"）
3. 目标用户是否已启用（用户管理页面查看）

### Q: 多张图片被拆分成多条消息？
A: 已修复。现在会检测媒体组并作为整体转发。如果仍有问题，请重启服务。
